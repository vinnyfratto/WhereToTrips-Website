Vibe Taxonomy

Every canonical vibe carries two groupings. Category is one global bucket, the same everywhere on earth. Shelf is the picker's accordion group, a parent → child tree packed per sub-region. Rename either, give either up to three images, and set the order. The grey code beside each name is the stable id everything joins on — it never changes, which is what makes renaming free. Which vibes sit in a group is decided in code and shown here read-only.
